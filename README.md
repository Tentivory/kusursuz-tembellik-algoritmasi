## Bu Nedir?

Bu proje, insanlık tarihinin **en önemli** yazılımıdır.  
NASA, CERN, MIT ve Eskişehir 4. Ağır Ceza Mahkemesi tarafından (henüz) onaylanmamıştır ama yakında onaylanacaktır.

`tembellik.py` dosyası, sizin günlük enerji seviyenizi alıp **kusursuz bir tembellik planı** üretir.  
Bilimsel formülümüz:

```
Tembellik Skoru = (Enerji × 0) + Rastgele Saçmalık × π
```

## Nasıl Çalıştırılır?

1. Python 3 yüklü olsun (yoksa yükleme, tembellik bozulur).
2. Terminali aç.
3. Şu komutu yaz:

```bash
python tembellik.py
```

4. Enerji seviyeni gir.
5. Planı oku.
6. Hiçbir şey yapma.

## Özellikler

- ✨ Yavaş yazdırma teknolojisi (gözlerin bile tembelleşsin)
- 🧠 Quantum tembellik hesaplayıcı (hayali)
